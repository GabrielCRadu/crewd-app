# Build APK local din main — plan de implementare

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `npm run apk` construiește pe acest PC un APK Android de release din `origin/main`, cu versiunea `1.0.N` (N = numărul de commit-uri de pe `main`), și îl pune în `C:\crewd-build\apk\`; `npm run apk -- --install` îl și instalează pe telefoanele legate prin USB.

**Architecture:** `app.config.js` extinde `app.json` și pune în config versiunea (din variabilele de mediu setate de script) și cheia Google Maps (din `.env.local`). `scripts/build-apk.mjs` ține un worktree git separat în `C:\crewd-build\src`, îl aduce la `origin/main`, rulează `expo prebuild` + Gradle `assembleRelease` acolo și copiază APK-ul. Calculele pure (versiune, nume de fișier) stau în `config/appVersion.js`, testate cu Jest.

**Tech Stack:** Expo SDK 58 (CNG, `npx expo prebuild`), Gradle (wrapper generat), JDK 21, Android SDK (build-tools 34/35, NDK 27, CMake 3.22.1), Node 26, git worktree, adb.

**Spec:** `docs/superpowers/specs/2026-11-14-build-apk-design.md`

## Global Constraints

- Branch: `radu/build-apk` (pornit din `main`). Push/merge doar la cererea utilizatorului; `main` se schimbă doar prin PR.
- Build-ul se face **doar din `origin/main`**, într-un folder separat cu cale scurtă: `C:\crewd-build\src`. Working copy-ul proiectului nu se atinge.
- Versiune: `versionName = "1.0.N"`, `versionCode = N`, `N = git rev-list --count origin/main`. Calculată la build; **nimic nu se comite** în repo pentru versiune.
- APK-uri: `C:\crewd-build\apk\crewd-1.0.N.apk`.
- Pachet Android: `com.crewd.app`. Nume afișat: `Crewd`. `userInterfaceStyle`: `dark`.
- Semnătură: cheia de debug din șablonul Expo (`android/app/debug.keystore`, generat de `prebuild`).
- `android/` și `ios/` nu se comit și nu se editează de mână (CNG, AGENTS.md); sunt deja în `.gitignore` (de verificat în Task 1).
- Secrete (`.env.local`, cheia Google Maps) nu se comit. Cheia de hărți: `GOOGLE_MAPS_API_KEY` în `.env.local`.
- Fără `git clean`, `git reset --hard` sau `push --force` (regulile echipei). Folderul de build se actualizează cu `git checkout --detach --force origin/main`.
- Fără EAS cloud. Fișiere comune atinse: `app.json`, `package.json` (doar un script nou), `.gitignore` (doar dacă lipsește ceva), `todo.md`.
- Teste: `import { describe, expect, it } from '@jest/globals'`, în `__tests__/*.test.ts`. Înainte de „gata”: `npx tsc --noEmit` și `npm test` trec.

## Review Focus

1. Lipsește `GOOGLE_MAPS_API_KEY` → scriptul se oprește **înainte** de build, cu mesaj clar (altfel APK-ul se deschide și pică pe tab-ul Hartă). (Test pentru `missingRequirements` în Task 2.)
2. Rulare a doua oară, după ce `main` a avansat → worktree-ul trece la noul `origin/main`, iar versiunea crește. Un `versionCode` mai mic refuză instalarea peste cea veche. (Test pentru `versionFromCommitCount` în Task 1; verificare manuală în Task 3.)
3. Ești pe alt branch, cu modificări necomise → build-ul ignoră complet working copy-ul (folosește doar `origin/main`). (Verificare manuală în Task 3.)
4. Niciun telefon conectat la `--install` → APK-ul rămâne construit, iar scriptul spune „Niciun telefon conectat”, fără să eșueze. (Test pentru `parseAdbDevices` în Task 2.)
5. Fără variabilele de versiune (Expo Go / `npx expo start`) → `app.config.js` păstrează versiunea din `app.json`, ca dezvoltarea zilnică să nu se schimbe. (Test pentru `applyBuildConfig` în Task 1.)

### Task 2: Scriptul de build

**Files:**
- Create: `scripts/build-apk.mjs`
- Create: `config/buildChecks.js` (funcții pure folosite de script)
- Create: `config/buildChecks.d.ts`
- Modify: `package.json` (`"apk": "node scripts/build-apk.mjs"`)
- Test: `config/__tests__/buildChecks.test.ts`

**Interfaces:**
- Consumes: `versionFromCommitCount`, `apkFileName` (Task 1).
- Produces:
  ```js
  // config/buildChecks.js
  missingRequirements({ javaFound, sdkDir, envFileText }) -> string[] // mesaje în română, gol dacă e totul ok
  parseAdbDevices(stdout) -> string[]                                 // doar serialele cu starea „device”
  ```

- [ ] **Step 1: Scrie testele care eșuează** (`buildChecks.test.ts`):
  - `missingRequirements({ javaFound: true, sdkDir: 'C:\\sdk', envFileText: 'EXPO_PUBLIC_FIREBASE_API_KEY=x\nGOOGLE_MAPS_API_KEY=k' })` → `[]`.
  - fără `GOOGLE_MAPS_API_KEY` (sau cu valoare goală) → conține un mesaj cu `GOOGLE_MAPS_API_KEY`.
  - `envFileText: null` (lipsește `.env.local`) → mesaj cu `.env.local`; `javaFound: false` → mesaj cu `Java`; `sdkDir: null` → mesaj cu `Android SDK`.
  - `parseAdbDevices('List of devices attached\nR3CX40JN6DF\tdevice\nemulator-5554\toffline\nABC\tunauthorized\n\n')` → `['R3CX40JN6DF']`; textul fără dispozitive → `[]`.
- [ ] **Step 2: Rulează** `npx jest config/__tests__/buildChecks.test.ts` — Expected: FAIL.
- [ ] **Step 3: Implementează** `config/buildChecks.js`, apoi `scripts/build-apk.mjs`, pași în ordine, cu un mesaj scurt în română la fiecare pas și oprire la prima eroare (cod de ieșire ≠ 0):
  1. Verificări: Java (`JAVA_HOME` sau `java -version`), SDK (`ANDROID_HOME` / `ANDROID_SDK_ROOT` / `%LOCALAPPDATA%\Android\Sdk`), `.env.local` din rădăcina proiectului → `missingRequirements`; dacă lista nu e goală, o afișează și iese.
  2. `git fetch origin main` în proiect.
  3. Worktree: dacă `C:\crewd-build\src` nu există → `git worktree add --detach C:\crewd-build\src origin/main`; altfel `git -C C:\crewd-build\src checkout --detach --force origin/main`.
  4. Copiază `.env.local` în worktree.
  5. `npm ci` în worktree doar dacă `package-lock.json` diferă de cel de la ultimul build (hash salvat în `C:\crewd-build\.lock-hash`).
  6. `N = git rev-list --count origin/main` → `versionFromCommitCount(N)`; setează `APP_VERSION_NAME`, `APP_VERSION_CODE`, `NODE_ENV=production` pentru pașii următori.
  7. `npx expo prebuild --platform android --clean --no-install` în worktree.
  8. `android\gradlew.bat assembleRelease` în `C:\crewd-build\src\android` (scrie `sdk.dir` în `android/local.properties` dacă `ANDROID_HOME` nu e setat).
  9. Copiază `android/app/build/outputs/apk/release/app-release.apk` în `C:\crewd-build\apk\<apkFileName>` și afișează calea + versiunea.
  10. Cu `--install`: `adb devices` → `parseAdbDevices`; pentru fiecare serial `adb -s <serial> install -r <apk>`; fără dispozitive → „Niciun telefon conectat; APK-ul e în …”, cod de ieșire 0.
  - Comenzile externe rulează cu `spawnSync(..., { stdio: 'inherit', shell: true })`, ca utilizatorul să vadă progresul Gradle.
- [ ] **Step 4: Rulează** `npx jest config/__tests__/buildChecks.test.ts` — Expected: PASS. Apoi `npx tsc --noEmit` și `npm test` — Expected: curat.
- [ ] **Step 5: Commit**
  ```bash
  git add scripts/build-apk.mjs config/buildChecks.js config/buildChecks.d.ts config/__tests__/buildChecks.test.ts package.json
  git commit -m "npm run apk: local release APK from origin/main in C:\\crewd-build, optional install over USB"
  ```
