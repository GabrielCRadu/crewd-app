# Chatul de grup în Firestore — plan de implementare

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Conversațiile grupurilor devin reale (mesaje în Firestore, în timp real), cu miniaturi de profil, ecran de Detalii ale grupului și „grup” în loc de „grupuleț” în interfață.

**Architecture:** Logica pură (rânduri de chat, separatoare de zi, validare, previzualizare) stă în `src/utils/chatRules.ts`, testată cu Jest. `src/services/chatService.ts` vorbește cu Firestore (sau cu un depozit în memorie fără `.env.local`, ca `groupsService`), iar ecranele folosesc doar hook-urile `useGroupMessages` / `useLastMessage`. Miniatura de profil (~96 px) se generează în `photoService`, se salvează în `users/{uid}.photoThumb` și se copiază în `members[uid].photo` din grup.

**Tech Stack:** Expo SDK 58, React Native, TypeScript, Firebase JS SDK (Firestore), `expo-image-manipulator`, React Navigation (native stack), Jest (`jest-expo`, `@jest/globals`).

**Spec:** `docs/superpowers/specs/2026-11-14-chat-grup-design.md`

## Global Constraints

- Branch: `radu/chat-firestore` (pornit din `main`). Nu se face push/merge fără cererea utilizatorului; `main` se schimbă doar prin PR.
- Ecranele nu vorbesc direct cu Firestore: doar prin `src/services/*` și `src/hooks/*` (AGENTS.md).
- Stil doar prin tokenii din `src/theme/` (monocrom, `docs/design-language.md`); fără culori puse direct în ecrane. Excepții: roșu (`colors.nope`) pentru „Ieși din grup”.
- Interfața în română; în textul vizibil se scrie **„grup”**, nu „grupuleț”. Numele din cod, comentariile și documentația internă rămân neschimbate.
- „Numele grupului” = **titlul evenimentului** (grupurile nu au nume propriu).
- Mesaj: `authorUid`, `authorName`, `text` (1–1000 caractere după trim), `createdAt` (timestamp de server). Fără update/delete.
- Miniatura: JPEG pătrat ~96 px, data URI; `users/{uid}.photoThumb` ≤ 20 000 caractere; în grup `members[uid].photo` (string sau `null`, **niciodată `undefined`**: Firestore refuză `undefined`).
- `firestore.rules` se modifică doar în fișier; **utilizatorul publică regulile** în consolă.
- `scripts/seed-groups.mjs` scrie în Firestore doar după acordul explicit al utilizatorului (proiect comun).
- Teste: `import { describe, expect, it } from '@jest/globals'`, în `__tests__/*.test.ts`. Înainte de „gata”: `npx tsc --noEmit` și `npm test` trec.
- Fișiere comune (`src/types`, `src/services`, `src/navigation/*Types.ts`, `firestore.rules`, `todo.md`): doar adăugiri și modificări minime.

## Review Focus

1. Utilizator fără poză care intră/propune un grup → `members[uid].photo` e `null` (nu `undefined`), altfel tranzacția eșuează. (Test în Task 4.)
2. Autorul a ieșit din grup → mesajele lui rămân cu `authorName` și inițiala (fără miniatură), fără crash. (Test în Task 1.)
3. Același autor înainte și după un separator de zi → numele apare din nou după separator. (Test în Task 1.)
4. Mesaj doar din spații sau peste 1000 de caractere → nu se trimite (`normalizeMessageText` întoarce `null`; câmpul are `maxLength` 1000). (Test în Task 1.)
5. Utilizatorul iese din grup cu conversația deschisă (sau e scos) → ascultarea dă `permission-denied`; ecranul arată „Nu mai ești în acest grup.” cu „Înapoi”, nu ecran gol. (Test în Task 2, pentru maparea erorii.)
